# 🦷 BrightSmile — Modern 3D Spa Dental Clinic & Wellness Studio

A spa-inspired gentle dental website built with **React Three Fiber**, **Three.js**, **Framer Motion**, and **Tailwind CSS**.

Featuring an **Anatomical 3D Porcelain Molar Tooth** with enamel translucency, cold laser whitening beam, orbiting precision instruments, diamond sparkle halo, interactive Before/After drag slider, and spa comfort menu.

### Quick Start
```bash
npm install
npm run dev
```
Visit `http://localhost:3003`
